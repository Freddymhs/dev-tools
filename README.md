# project-resume

Genera un `RESUME.md` con todo el código fuente de un proyecto — para compartir contexto con una IA o trabajar offline.

## Uso

```bash
npm run generate   # genera RESUME.md en el proyecto configurado
npm run split      # divide RESUME.md en partes de 10k líneas (opcional)
npm run run-all    # ambos en secuencia
```

> También acepta argumento directo: `node generate_resume.cjs /ruta/al/proyecto`
